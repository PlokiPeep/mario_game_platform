# Mario Game Platform

A Mario-style platformer built with HTML5 Canvas and vanilla JavaScript.

## Play the game

**[Click here to play!](https://plokipeep.github.io/mario_game_platform/)**

## Controls

| Key | Action |
|-----|--------|
| Arrow Left / A | Move left |
| Arrow Right / D | Move right |
| Space / W / Arrow Up | Jump |

## Features
- Pixel art sprites
- Parallax scrolling background
- Coins, ? blocks, and Goombas
- Screen shake and particle effects
